## 2. Contexto

Debate estruturado com inversão de papéis: metade do grupo defende "Lançar Agora" (perspectiva Dev) e a outra defende "Atrasar e Testar" (perspectiva QA).

**Objetivo de aprendizagem:** Desenvolver empatia cognitiva entre perfis Dev e QA. Fundamentado nos construtos E3.1 (Socialização) e E1.4 (Aprendizado), conforme Ju et al., ICSE 2021, Tabela III.

## 2. Contexto

Facilitação estruturada de retrospectiva ágil seguindo o modelo de 5 atividades de Derby & Larsen: Set the Stage → Gather Data → Generate Insights → Decide What to Do → Close the Retrospective.

**Objetivo de aprendizagem:** Desenvolver habilidade de reflexão crítica coletiva e cultura de melhoria contínua. Fundamentado nos construtos E3.x (Socialização) e E2.x (Confiança), conforme Ju et al., ICSE 2021, Tabela III.

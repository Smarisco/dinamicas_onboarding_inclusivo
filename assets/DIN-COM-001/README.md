## 2. Contexto

Simulação de navegação verbal em campo com objetos: um participante atravessa o campo guiado exclusivamente pelas instruções verbais do parceiro.

**Objetivo de aprendizagem:** Desenvolver comunicação precisa, escuta ativa e confiança mútua entre pares Sênior/Júnior. Fundamentado nos construtos E3.1 (Socialização) e E2.5 (Confiança), conforme Ju et al., ICSE 2021, Tabela III.

## 2. Contexto

Prática estruturada de comunicação assertiva em que os participantes exercitam formular pedidos claros a partir de cartões de cenário do contexto de desenvolvimento de software.

**Objetivo de aprendizagem:** Capacitar profissionais em onboarding a expressar necessidades de forma direta. Fundamentado nos construtos E3.x (Socialização) e E2.x (Confiança), conforme Ju et al., ICSE 2021, Tabela III.

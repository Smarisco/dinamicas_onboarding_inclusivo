## 2. Contexto

Dinâmica para praticar feedback estruturado e comunicação não-violenta seguindo o Modelo Pendleton (4 passos).

**Objetivo de aprendizagem:** Desenvolver habilidade de dar e receber feedback de forma construtiva, empática e eficaz. Fundamentado nos construtos E3.x (Socialização) e E2.x (Confiança), conforme Ju et al., ICSE 2021, Tabela III.

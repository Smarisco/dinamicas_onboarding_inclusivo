## 2. Contexto

Prática repetitiva (kata) em que o participante implementa um problema simples seguindo estritamente o ciclo TDD: Red → Green → Refactor.

**Objetivo de aprendizagem:** Internalizar a disciplina do ciclo Red-Green-Refactor. Fundamentado nos construtos E1.x (Aprendizado) e E2.x (Confiança), conforme Ju et al., ICSE 2021, Tabela III.
